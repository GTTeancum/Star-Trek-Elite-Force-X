# PS2 comparison and Xbox memory options

The correct R5900 project completed and saved. `receiver_loader_decompilation.json`, `pmp_virtual_decompilation.json` and `ps2_geometry_decompilation.json` supersede generic MIPS output for the functions they cover. `redrocket_20260913/geometry_assembly_review.json` retains reviewed instructions for whole-lump read/temporary allocation and triangle allocation. This is loader/representation RE, not a claim to understand the entire executable.

PS2 compressed archives have per-owner read caches and both whole-entry decode and resident-entry partial-read modes. Uncompressed CD.PMP contains the BSPs. Filename hash identification matched59 independently entity-identified BSPs. Matched borg1 files differ by only4,032 bytes overall; file-size difference does not establish runtime savings. PS2 world surfaces retain16-byte descriptors and allocate multiple input lumps concurrently. Triangle payload allocation is64+44*vertices+4*indices. These findings favor comparing exact representations and lifetime rather than assuming half the platform RAM means every asset is half-sized.
